# Provenance

This public repository was exported on **2026-08-13** from WebsiteBench
pipeline commit `58634e2`. That pipeline checkout was originally extracted
from the WebsiteBench main repository at source commit
`bbeb051899c83482b0c661dc29ec5ab08fba8062`.

## Public-export transform

- The export starts from a new root commit, so excluded evidence is not
  reachable through Git history.
- `materials/tripit/`, `harbor/sites/tripit/`,
  `harbor/instances/tripit/`, and TripIt-specific deployment/workflow files
  were excluded because the sample's own rights review does not grant public
  redistribution of captured trademarks, page content, images, or fonts.
- The Amazon source/clone/diff showcase screenshots under the viewer static
  tree were likewise excluded because no public redistribution grant was
  recorded for those visual-evidence files.
- The prior repository's historical deployment-authorization record was
  excluded; it does not authorize publication from this repository.
- Public-facing documentation and site-specific deployment tests were adjusted
  only where necessary to describe the exported file set accurately.
- Local checkout paths, credentials, runtime state, ignored files, and the
  original repository's Git history are not part of this export.

The original local repository, its three commits, and all immutable evidence
identities remain unchanged.
